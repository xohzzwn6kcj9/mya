표기: `S`/`M`/`L` 난이도 · ⭐ 종합 매력도(1~10) · 🎯 시그니처 ⚡ 즉효 🚀 야심작 ⏭️ 병합·보류 권장 · 🔒 백엔드(serverless) 필요

## 네 갈래로 수렴

1. **의미 레이어** — "먀"를 뜻·문법·어휘를 가진 살아있는 언어로 확장
2. **대화 레이어** — 일방향 토이를 URL 인코딩으로 비동기 편지를 주고받는 통로로
3. **맥락 엔진** — 날짜·시각·날씨·기념일이 화면 분위기를 자동으로 빚음
4. **감각 레이어** — 사운드·햅틱·제너러티브 배경으로 빈 화면조차 살아있게

공통점: 대부분 백엔드 없이 localStorage·URL 인코딩·클라이언트 시각만으로 완결. 가장 강한 아이디어는 새 기능 추가보다 **기존 메커니즘(랜덤 생성·당구공 물리·계절 테마 엔진·숨은 쿠키 게이트)에 '의미'와 '감각'을 얹어 승격**시키는 것.

## 공유 리팩터링 (여러 아이디어의 선행 조건)

- **`buildMessageText(item)` 헬퍼 추출** — 현재 `+page.svelte`의 메시지 조합 삼항식이 본문(L918)·잔상(L901) 두 곳에 중복. 사전·인사·편지·메아리 등 다수 아이디어가 이 한 곳을 공유해야 함. 가장 먼저 추출.
- **AudioContext 싱글톤 + mute 스토어** — 모든 사운드 아이디어가 공유하는 인프라. "오디오 진입 의식"이 이걸 깔아줌.
- **롱프레스 제스처 분리** — 기존 드래그-던지기(`handleItemDragStart`)와 배타. 이동 임계값(약 8~10px) 초과 시 타이머 취소로 분기. 사전·비밀편지·먀 한 마리·체온 글로우·캡처 등이 공유.

## 채택 방향: 감각·비주얼 레이어 (테마 ⑧ + ⑨)

> 2026-05-31 결정. 기존 인터랙션을 건드리지 않고 화면을 "살아있게" 만드는, 안전하면서 체감이 큰 묶음. 아래 의존 순서로 증분 빌드.

**Phase 0 — 토대**
1. `buildMessageText` 헬퍼 추출 (위 공유 리팩터링)
2. ⚡ **오디오 진입 의식** `S` ⭐9 — AudioContext 싱글톤 + 첫 탭 resume + `navigator.vibrate(15)` + 우하단 절제된 음소거 토글(localStorage). **모든 사운드의 관문.**

**Phase 1 — 비주얼 (사운드와 독립, 병행 가능)**
3. 🎯 **살아있는 보케 배경** `M` ⭐9 — `BokehField.svelte` 신규. `<main>` 첫 자식 z-index:0/pointer-events:none. radial-gradient + blur(40px) 입자 7~10개, 화면 3~6% 이내 초저속 표류(duration 22~40s), 색은 `currentTheme.heartColors` 따라감. `prefers-reduced-motion` 정지. RAF 불필요(순수 CSS).
4. ⚡ **숨결 잔상 (Aurora Trail)** `S` ⭐8 — 기존 trail(L888-902)의 단색을 잔상 인덱스 비례 `color-mix(in oklch, base, neighbor)`로 보간. 속도 클수록 길고 진하게. 물리 엔진 무수정.
5. ⚡ **잔향 메아리** `S` ⭐7 — 탭 시 거대·흐린 복제본이 제자리 scale 1→1.4 + opacity 0.4→0 fade-out. 신규 `@keyframes echo-ripple`(translate(-50%,-50%) 유지 = 위치 이동 아님).
6. 🎯 **테마 전환 디졸브** `M` ⭐8 — `shouldChangeTheme()` 분기에서만. 탭 좌표 기준 `clip-path: circle(0% → 150%)` 0.6s 잉크 디졸브. reveal이라 원칙 안전.

**Phase 2 — 사운드 (Phase 0 의존)**
7. 🎯 **먀의 목소리** `M` ⭐9 — `audio/voice.ts`. colorIndex→pentatonic 음정, fontSize→옥타브, positionX→StereoPanner. 마스터 -6dB 클리핑 방지. `Theme` 인터페이스에 선택적 `sound` 필드(wave/scale/attack/decay) + 테마별 12 프리셋.
8. 🎯 **'사랑해'에만 들리는 숨은 멜로디** `S` ⭐9 — `showSpecialMessage` 분기 시 4음 아르페지오 + `vibrate([60,40,60])`. voice.ts 위 저비용. 멜로디는 number[]라 노출 무해.
9. 🎯 **던지고 부딪히는 충돌음 + 햅틱** `M` ⭐8 — `updatePhysics`의 벽 반사(L747-762)·글자 충돌(L790)에 콜백. 음정=질량(fontSize², 이미 L618 계산) 역매핑, 볼륨=속도차. 프레임당 N회·임팩트 임계로 throttle.

**Phase 3 — 후속(선택)**
10. 🚀 **체온 글로우(꾹 누르면 후광)** `M` ⭐6 — 롱프레스 인프라 의존.
11. 🚀 **은은한 앰비언트(배경 숨소리)** `L` ⭐6 — 기본 OFF, visibilitychange suspend.

⏭️ 보류: 숨은 별자리(⭐5, 발동 조건 자주 깨짐) · 가변폰트 호흡(⭐3, 현 27종 폰트셋 미지원) · 진짜 목소리 녹음(보안 충돌, 합성 voice로 대체) · 공유 사운드 시그니처.
